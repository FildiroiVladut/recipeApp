# forkify

Recipe search app: search recipes, scale servings, build a shopping list and save favourites (persisted in `localStorage`).

**Live demo:** https://fildiroivladut.github.io/recipeApp/

Built with vanilla JavaScript (ES6+, MVC architecture), bundled with Webpack and Babel. Recipe data comes from the [Forkify API](https://forkify-api.herokuapp.com). Originally a project from Jonas Schmedtmann's JavaScript course.

## Run locally

```bash
npm install
npm start        # dev server
npm run build    # production build in dist/
```

Pushing to `master` builds and deploys to GitHub Pages via GitHub Actions.
